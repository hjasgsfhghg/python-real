# 11.23

关于MVP架构

    model层只依赖numpy、cv2、torch

    view只依赖pyside6

    presenter同时认识两边类

model 应该实现的功能

    游戏本体、数据采集、数据训练、手势识别

view 应该实现的功能

    四子棋界面显示、四子棋数据显示、摄像头显示、图像识别结果/数据显示

presenter 应该实现的功能

    如果view调整了四子棋游戏状态，传输给model的游戏本体

    如果view调整了图像识别模式/设置，传输给model游戏本体

    model识别摄像头手势结果，修改游戏后，反馈给view(包含摄像头识别结果和游戏修改后结果)

创建Qt对象有严格顺序

    1. QApplication(sys.argv)          ← 必须是第一个 Qt 对象，且全程序只有一个
    2. 构造 model / service           ← 纯 Python，不碰 Qt（摄像头、棋局、识别器）
    3. 构造 MainWindow(view)          ← 此时 QApplication 已存在
    4. 构造 Presenter(view, model...)  ← 在这里 connect 信号、启动 QTimer
    5. window.show()                  ← 调用 Qt 原生 show，不再重写
    6. app.exec()                     ← 进入事件循环，窗口才真正“活着”
    以上将体现在main.py
